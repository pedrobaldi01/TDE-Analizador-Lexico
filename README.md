# TDE de Linguagens Formais — Analisador léxico do item t)

Analisador léxico em HTML, CSS e JavaScript. O autômato reconhece cadeias binárias que começam com `1` e têm uma quantidade ímpar de uns, ou começam com `0` e têm uma quantidade ímpar de zeros.

## Como executar

1. Abra `index.html` em um navegador. O programa funciona offline e dispensa instalação.
2. Digite uma cadeia binária para acompanhar as transições do autômato.
3. Pressione **Espaço** para validar a cadeia. Clique no resultado no histórico para ver o percurso.

Experimente `1011` e `0100`, que são reconhecidas, e `101` e `010`, que são rejeitadas.

## Referência

A interface se inspira no analisador léxico de Emily L. Balestrin e Júlia F. Levandoski. [Repositório de referência](https://github.com/EmilyBalestrin/AnalisadorLexico)
